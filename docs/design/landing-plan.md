## 왜 다시 하는가

2026-10-12 서비스명을 SecretTome으로 바꾸면서 제품이 앞세우는 것이 **"현장에서 해 본 사람이 쓴 책 — 내 일에 바로 적용"**으로 정해졌습니다. 메인 페이지(`src/app/page.tsx`, `src/components/landing/*`)는 그 전인 10-01 톤("바로 써먹는 지식을 짧게 읽는다")과 리뉴얼 1차(토큰만 교체) 상태에 머물러 있습니다.

## 정한 것

- **시안 A(책 먼저)로 갑니다.** 왼쪽 정렬 메인 영역 → 새로 나온 책 → 적용 섹션(본문 + 체크리스트 예시) → 저자로 참여하기 블록 → 푸터.
- **메인 영역(hero)에는 워크북을 드러내지 않습니다.** 워크북은 도구이지 핵심 가치가 아니고, 첫 화면에 내세우면 초기 독자가 무슨 서비스인지 헷갈립니다. hero에서는 "체크리스트·질문·답 저장"과 "워크북"이라는 단어를 쓰지 않습니다. 워크북은 아래 섹션에서만 보여 줍니다.
- **저자로 참여하는 입구는 하단에 짧은 블록 하나만 둡니다.** hero는 독자 전용입니다.

## 시안 A 구성

| 순서 | 내용 |
|---|---|
| 메인 영역 | 왼쪽 정렬. h1 "해 본 사람이 쓴 책을, 내 일에 바로 적용해 보세요" / 설명 "현장에서 직접 부딪혀 본 사람이 쓴 책이에요. 그 사람이 실제로 쓰던 방법을 내 일에 그대로 가져가 보세요." / accent 버튼 [책 둘러보기] 하나 + "첫 장은 사지 않아도 읽을 수 있어요" |
| 새로 나온 책 | `BookPreviewCard` 4열(표지 최대 210px). 메타에 저자 이름 · 가격, 그 아래 **저자 현장 이력 한 줄**(`user_profiles.bio`) |
| 적용 섹션 | 라벨 "읽는 책이 아니라 적용하는 책" + 짧은 설명 / 오른쪽에 본문 한 단락 + 체크리스트 블록 정적 예시 |
| 저자 블록 | "현장에서 쌓은 노하우를 책으로 내 보세요" + secondary 버튼 [크리에이터로 시작하기] |
| 푸터 | "All rights reserved." 영어 문장 제거, 타이포 토큰으로 |

## 같이 빼는 것 (DESIGN.md 위반·불필요)

- 가운데 정렬 hero, hero 검색창(헤더 검색과 중복), "지금 읽을 수 있는 책 N권"
- framer-motion 진입·스크롤 애니메이션(`HeroSection`, `BookSection`), 스켈레톤 `animate-pulse`
- `FeaturesSection`(아이콘 + 제목 + 설명 3열) — 적용 섹션으로 대체
- 토큰 밖 글자 크기(`text-5xl md:text-7xl` 등), 빈 "그라데이션 블러" 주석

## 구현 때 정할 것

- 모바일 h1 크기: 보드는 28px로 그렸는데 타이포 토큰에 없습니다. 32px로 둘지 토큰을 추가할지.
- 적용 섹션의 체크리스트는 리더 템플릿을 쓸 수 없습니다(`WorkbookResponsesProvider` 밖에서 그리면 던짐). 같은 시각 언어의 정적 랜딩 전용 컴포넌트로 만듭니다.
- 저자 bio: `src/app/api/landing/route.ts`의 `fetchAuthorMap`이 `display_name`만 읽음 → `bio`도 읽기. bio가 빈 저자는 줄을 생략.
- 책이 0권이거나 목록 조회에 실패했을 때 섹션이 통째로 사라지는 문제 — 빈 상태 안내 추가.
- 페이지 전체가 `"use client"`라 검색 노출이 약함(README에서 "M6 이후"로 미룬 부채). 이번에 서버 컴포넌트로 바꿀지.
- 같은 이유로 고칠 문서: `/about` hero 설명(워크북을 앞세움), `DESIGN.md` `## Voice`의 톤 문장(10-01 기준).

## 구현 때 정한 것 (2026-10-19)

- 모바일 h1은 새 토큰을 만들지 않고 기존 `display` 모바일 값 25px(`max-[600px]:text-[25px]`)을 씁니다. 탐색·책 상세·리더 h1과 같습니다. 쉼표 뒤에서 줄을 끊습니다.
- 체크리스트 예시는 `WorkbookBlock` 틀로 그린 정적 예시(`ApplySection`)입니다. 누를 수 없게 했습니다 — 눌러지면 저장되는 줄 압니다.
- 저자 bio는 `/api/landing`이 `author_bio`로 싣고, `BookPreviewCard`가 비어 있지 않을 때만 한 줄(말줄임)로 그립니다. 탐색 API는 싣지 않으므로 탐색 카드는 그대로입니다. 안 쓰게 된 `stats.totalBooks` 조회는 뺐습니다.
- 책 0권은 `BookGrid`의 빈 상태, 조회 실패는 안내 + [다시 불러오기]를 섹션 안에 그립니다.
- `page.tsx`는 서버 컴포넌트입니다. 메인 영역·적용 섹션·저자 블록 문구는 HTML로 나가고, 책 목록(`NewBooksSection`)만 클라이언트에서 불러옵니다. 목록까지 서버에서 그리면 빌드 시 Supabase 환경변수가 필요하고 실패 화면이 캐시될 수 있어 미뤘습니다.
- `framer-motion`은 랜딩만 썼으므로 의존성에서 뺐습니다.
