이번 챕터는 단 하나의 목표를 가지고 있어요. 지금 당장, 손으로 직접, 자소서 초안을 만들어보는 것.

이론 설명은 없어요. 설치 이야기도 없어요. Claude Code를 열고, 5분 뒤엔 여러분의 이름이 들어간 자소서 초안이 파일로 저장되어 있을 거예요.

시작하기 전에 확인해요

Claude Code 시작하기

터미널을 열어요. macOS라면 Cmd + Space를 눌러 Spotlight에서 “터미널”을 검색하고, 아래 명령어를 입력해요.

mkdir my-resume-pipeline
cd my-resume-pipeline
claude

mkdir은 폴더를 만드는 명령어예요. cd는 그 폴더 안으로 들어가는 명령어고요. 마지막으로 claude를 치면 Claude Code가 시작돼요.

참고

Claude Code가 설치되어 있어야 해요. Claude Pro 또는 Max 구독이 필요해요. 설치가 처음이라면 0장을 먼저 확인하세요.

A 절제: 볼 것

  • Rosewood가 버튼, 진행 바, 선택된 척도 칸에만 있어도 브랜드가 느껴지는가
  • Botticelli 입력 면만으로 “내가 쓰는 영역”이 구분되는가
  • 세 안 중 가장 “도구적”이다. 대신 밋밋하지 않은가

B 크림: 볼 것

  • Chiffon 전면 바탕이 긴 본문을 읽을 때 눈에 피로하지 않은가
  • 헤딩과 링크의 Rosewood가 Coffee 본문과 구분되는가(대비 1.39, 명도 차이가 거의 없음)
  • “가벼운”과 가장 멀다. 따뜻함이 그 값을 하는가

C 블록 대비: 볼 것

  • 성찰(Chiffon)과 체크리스트·척도(Botticelli)로 역할이 나뉘는 것이 읽히는가
  • 블록이 많은 장에서 면색이 번갈아 나오면 산만하지 않은가
  • 흰 바탕 위 Chiffon 면은 테두리 없이는 안 보인다(대비 1.08)
